# 📋 Quadro de Tarefas - Java

Sistema simples de gerenciamento de tarefas estilo Kanban desenvolvido em Java.

## 📝 Descrição

Este projeto permite criar e gerenciar boards de tarefas com colunas personalizáveis. Você pode criar cards, movê-los entre colunas, bloquear tarefas e muito mais!

## 🚀 Funcionalidades

- ✅ Criar múltiplos boards
- ✅ Criar cards com título e descrição
- ✅ Mover cards entre colunas (A Fazer → Em Progresso → Concluído)
- ✅ Bloquear e desbloquear cards
- ✅ Cancelar cards
- ✅ Visualizar board completo

## 🛠️ Tecnologias

- Java 8+
- Conceitos de Orientação a Objetos

## 💡 Como usar

1. **Criar um Board**: Selecione a opção 1 no menu principal
2. **Selecionar Board**: Escolha um board existente para trabalhar
3. **Criar Cards**: Dentro do board, adicione novas tarefas
4. **Mover Cards**: Mova as tarefas entre as colunas conforme avançam
5. **Gerenciar**: Bloqueie, desbloqueie ou cancele cards conforme necessário
